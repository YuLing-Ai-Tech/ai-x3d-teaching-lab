## 第 1 课：AI 只有语言（第 1–4 页）

### 0–5 分钟：开场（第 1–2 页）

> 今天只讲一个判断：大语言模型就是语言的模型。它没有眼睛和手，只有语言。谁能把话说清楚，谁就能让 AI 把世界造出来。

### 5–22 分钟：词向量宇宙（第 3 页 → 打开）

- 准备：右上角选学段（初中只做任务 1）；按 T 打开教师提示。开场演示用“语言”页签：翻页笔切换“猫 → cat → 数学 → 爱 → king − man + woman → 东京 − 日本 + 中国 → 国王 − 男人 + 女人”；学员探究切回“探究”页签（翻页笔在这里不切预设）。
- 操作（预测 → 操作 → 证据 → 解释 → 评价，面板会锁定顺序）：
  1. 任务“中英文同义词靠得近吗”：在“两个词比一比”里点“猫–cat”“猫–狗”“猫–数学”，读数据卡：约 0.81 / 0.68 / 0.50，而任意两词平均约 0.48——“不相关”不是 0，而是平均水平；再点“马–horse”（约 0.49），同义词也有例外；
  2. 高中任务“类比总是成立吗”：king − man + woman ≈ queen 命中，“国王 − 男人 + 女人”却最接近“公主”，“王后”排第 5——至少记录一组未命中；
  3. 高中任务“图上的远近可信吗”：“猫–cat”相似度排第 1，三维图上却排第 34；“老虎–语言”图上只相距约 2.3，相似度约 0.45，低于平均。
- 提问：**如果“意思”是空间里的位置，判断两个词“近不近”，应该和什么比？**
- 结论句：**AI 用数字表示“意思”；数字要有基准，类比要用名次检验，图上的远近要回到 1024 维数据核对。**
- 边界：向量来自 bge-m3，课前离线计算；三维位置是 t-SNE 投影，只尽量保留“谁和谁是邻居”，距离不能直接读。
- 回退：30 秒没进入预期状态，只用左侧“两个词比一比”和“类比”的数据卡（不依赖三维动画）；仍不行播放备用录像并板书：猫–cat 0.81、猫–狗 0.68、猫–数学 0.50，平均 0.48；国王 − 男人 + 女人 → 公主（王后第 5）。

### 22–40 分钟：下一个词（第 4 页 → 打开）

- 准备：选学段（初中只做任务 1、3，不出现熵和温度）；按 T 打开教师提示。预测锁定前光柱和数据卡被遮住；“语言”页签不遮，可用于开场演示。
- 操作（预测 → 操作 → 证据 → 解释 → 评价）：
  1. 任务“哪句最确定、哪句最犹豫”：六句前文建议全记，再请学员按第一名概率排队——霜 99.82%、勾股定理 → c 99.63%、牛顿第二定律 → ma 97.09%、长河 → 落日 96.34% 在前；Paris 只有 62.3% 居中；“学生最重要的能力是 → 提问”10.53% 在最后，与第二名“（”7.24% 只差 3.3 个百分点；
  2. 高中任务“温度”：选“The capital of France is”，点温度 0.5 / 1.5：Paris 从 99.0%（熵 0.11 比特）降到 56.5%（熵 2.20 比特），排名不变；
  3. 任务“‘提问’只有 10.5%”（开放题，不判对错）：读全部 8 个候选和整句续写“提问能力。↵A. 对”——模型把这句话当成了判断题或填空题。
- 提问：概率最高的就是正确答案吗？“提问”排第一，能说明提问最重要吗？
- 结论句：**确定的语言，得到确定的回答；模糊的问题，AI 也只能猜。概率说的是“常见”，不是“对”，更不是“重要”。**
- 边界：每一步只存了前 8 个候选，熵和温度都只在这 8 个里重新归一，是近似；原模型已不在本机，现场不能输入新句子。
- 回退：30 秒没进入预期状态，只看左侧数据卡（与画面无关）；WebGL 打不开就播放备用录像，按霜 99.82%、Paris 62.3%、提问 10.53% 讲；全部失效时板书“学生最重要的能力是 ___”，统计全班答案分布。

## 第 2 课：语言为王（第 5–6 页）

### 0–25 分钟：语言编译台（第 5 页 → 打开）

- 准备：选学段（初中做任务 1、2、4，高中做全部四个）；按 T 打开教师提示。开场先说一句“请给我一个漂亮的球”，让全班写下心中的半径。
- 开场演示用“语言”页签：翻页笔切换“球 · 中文 → Helix · English → 弹簧 → 圆锥 → 波浪面 → 圆环 → 说不清楚”，讲解卡给出同一形状的中文、英文、数学、代码四种写法，模糊词标红。
- 操作（“探究”页签，预测 → 操作 → 证据 → 解释 → 评价；锁定预测后数据卡和四种写法才出现）：
  1. 任务“模糊词交出了什么决定权”：点“漂亮的球”——“漂亮”被忽略，半径用默认值 2；再点“大一点的圆锥”：底面半径用 2、高用 3；
  2. 任务“改写到 0 个被猜参数”：在“我的描述”里一次次改写，直到数据卡显示“被猜参数 0”（如“一个底面半径 2、高 4 的圆锥”）；再点“半径 10 的球”，看它被改成上限 4；
  3. 高中任务“同一个世界”：点“半径 2 的球”→“钉住这句作对照”，再点 English、代码式：同一个世界；“A ball”只是“看似相同”（靠默认值）；数学式 x² + y² + z² = 4 解析器读不懂；
  4. 任务“哪种写法最好”（开放题）：至少 3 种语言形态各记一行，比较被猜、被改动、能否读懂。
- 提问：删掉模糊词，描述就清楚了吗？（“一个球”没有模糊词，半径照样被猜。）四种写法里哪一种最精确、哪一种机器最容易执行？
- 结论句：**中文、英文、数学、代码都是语言，都在用符号表达关系。没说出口的数量，都是交给机器的决定权。**
- 边界：这是一台只认识五种形状、默认值写死的教学解析器，不是大模型。
- 回退：30 秒没进入预期状态，只看左侧数据卡（不依赖 3D）；WebGL 打不开就播放备用录像，板书“一个漂亮的球”让学员报半径；全部失效时两人一组，一人描述形状、一人照着画，圈出被“猜”的地方。

### 25–42 分钟：古诗即几何（第 6 页 → 打开）

- 操作：先看原句“大漠孤烟直，长河落日圆”，然后依次切换“直 → 斜”“圆 → 缺”“孤 → 群”“日 → 月”。
- 讲解：“直”是一条垂线，“圆”是一个圆，“长河”是一条水平线。王维用十个字写了一份不可能画错的构图规格书。
- 提问：把“直”换成“斜”，画面多了什么看不见的东西？（风。）
- 结论句：**好的语言，一个字就能带出一个物理条件。**

## 第 3 课：英语与数学（第 7–8 页）

### 0–20 分钟：介词即空间（第 7 页 → 打开）

- 准备：选学段（初中只做任务 1、2）；按 T 打开教师提示。开场可在“语言”页签用翻页笔过一遍位置类（on、under、in、above、between、behind）和路径类（through 隧道、through 窗户、across、around、over、into）。
- 操作（“探究”页签，预测 → 操作 → 证据 → 解释 → 评价）：
  1. 任务“位置即条件”：点 on、under、in，看判定卡把每个介词拆成可检查的条件——on 要求底面贴着顶面且在投影范围内，悬空就是 above；
  2. 任务“through 与 over”：点“through 隧道”“over”记录；再在“语言”里写 The car goes through the box——盒子没有开口，不成立；
  3. 高中任务“behind 取决于谁”（开放题）：点 behind 先判定一次，拖动画面转到盒子后面，点“按当前视角重新判定”再记录。
- 提问：on 到底是什么意思？through the box 为什么不行？绕到盒子后面，behind 还对吗？（语言里藏着一个“观察者”。）
- 结论句：**介词就是一组可以检查的空间条件：位置介词是一个位置，路径介词是一条路径。**
- 边界：判定用长方体包围盒，是简化模型；盒子把 +z 当作“前方”是一种约定。
- 回退：30 秒没进入预期状态，只看判定卡（不依赖动画）；WebGL 打不开就播放备用录像，用课桌、书包现场摆放；全部失效时请两名学员站位演示 behind，第三名从前后两侧描述。

### 20–42 分钟：圆锥曲线切出来（第 8 页 → 打开）

- 准备：右上角选学段（初中只做任务 1、2）；按 T 打开教师提示可看课标、常见错误和 30 秒回退。
- 操作（预测 → 操作 → 证据 → 解释 → 评价，面板会锁定顺序）：
  1. 任务“截线谱”：先让学员锁定预测，再把 β 从 90° 拖到 0°，每种曲线记一行证据（β、类型、闭合、e）；
  2. 任务“临界在哪里”：点“贴合母线”，再按 ← → 微调 1°，全班喊“合上 / 打开 / 两支”；高中把 α 改成 20°、40° 再找一次——抛物线跟着母线走，不是 45°；
  3. 高中任务“离心率与位置”：固定 β 平移 h，e 不变——图形只是放大；
  4. 高中任务“定义从哪来”：打开 Dandelin 双球、焦点与准线、动点 P，|PF₁| + |PF₂| 始终等于 2a；
  5. 点“正对切面看真实形状”，对照右下角摊平的直角坐标方程。
- 提问：决定曲线类型的到底是哪一个量？为什么切面平移不改变离心率？
- 结论句：**数学是表示关系的语言。β 与 α 的一个大小关系，决定了三种曲线；一句“切线长相等”，推出了椭圆的定义。**
- 回退：WebGL 打不开就播放备用录像；电脑全失效，用手电筒斜照墙面——光锥就是圆锥。

## 第 4 课：物理与化学（第 9–10 页）

### 0–22 分钟：一句话定义引力（第 9 页 → 打开）

- 准备：选学段（初中只做任务 1、3，只讲“绕着转 / 掉下去 / 飞出去”）；按 T 打开教师提示。“探究”页签里预测锁定后模型才运行；“语言”页签里画面照常运动，可用翻页笔切到 English：同一条定律，换一种语言来写。
- 操作（预测 → 操作 → 证据 → 解释 → 评价）：
  1. 任务“三条定律的命运”：点“平方”“2.1 次方”“立方”，看火星：平方时近日点每圈几乎不动（小于 0.5°）；2.1 次方每圈同向进动约 20°，轨迹变成花瓣；立方没有稳定轨道，内侧坠落、外侧逃逸；
  2. 高中任务“进动有多大”：2.1 次方下观测地球和火星，实测约 19.8–20.0°，对照近圆理论值约 19.5°；
  3. 任务“中心质量变了”：保持“平方”，点 ×0.5、×1、×2——质量减半火星飞走，加倍轨道收紧；
  4. 高中任务“反例与模型边界”：“一次方”稳定但每圈倒退约 105°；“正比”闭合，每半圈一个近日点。
- 提问：为什么偏偏是“平方”？（力线从一点向球面扩散，球面积 ∝ r²；闭合轨道只出现在平方反比与正比。）轨道不闭合，是程序算错了吗？（看能量误差这一列，远小于 0.1%。）
- 结论句：**一句话定义一个宇宙：“平方”换成“2.1 次方”，轨道就不再闭合。**
- 边界：平面两体模型，恒星固定、行星看作质点，忽略行星间引力与相对论；数据都是模型单位，只比较趋势与角度。
- 回退：30 秒没进入预期状态，只看右侧“观测数据”（与画面无关、照样可记录）；WebGL 打不开就播放备用录像，用教师提示里的参考数据讲；全部失效时用绳子拴小球甩，松手说明“速度太大就飞走”。

### 22–42 分钟：分子也有语言（第 10 页 → 打开）

- 准备：选学段（初中只做任务 1、2、3 的定性部分）；按 T 打开教师提示。开场不要说“CCO 能喝”：乙醇是酒类饮品中的一种成分，工业酒精、高浓度乙醇不能饮用。“苯”“阿司匹林”“咖啡因”只在“语言”页签的预设里，可课末用翻页笔展示（数字表示成环）。
- 操作（“探究”页签，预测 → 操作 → 证据 → 解释 → 评价）：
  1. 任务“CCO 与 COC”：点 CCO →“设为对照”→ COC：分子式都是 C₂H₆O，氧一个是 C–O–H（羟基），一个是 C–O–C（醚键）——同分异构体；
  2. 任务“正丁烷与异丁烷”：CCCC 主链 4、支链点 0；CC(C)C 主链 3、支链点 1，括号就是支链；
  3. 任务“单键、双键、三键”：依次点 CC、C=C、C#C，高中读键长约 1.51 / 1.34 / 1.20 Å，乙烯共面、乙炔共线；
  4. 高中任务“模型能推出沸点吗”：看“实验数据”卡（NIST）：乙醇约 351.5 K、二甲醚约 248 K；正丁烷约 273 K、异丁烷约 262 K。
- 提问：分子式相同，就是同一种物质吗？哪些话是模型说的，哪些必须由实验数据说？
- 结论句：**语言里的“语序”，在化学里就是结构；性质要由实验数据来说，再用结构去解释。**
- 边界：三维构象由 RDKit 在课前离线计算，球棍比例是示意；沸点为 101.325 kPa、纯物质条件。
- 回退：30 秒没进入预期状态，只看右侧对照表与数据卡（不依赖 3D）；WebGL 打不开就播放备用录像，板书 CCO / COC 结构式；全部失效时用磁贴拼 2 个碳、1 个氧、6 个氢，看能拼出几种连接方式。

## 第 5 课：生物与地理（第 11–12 页）

### 0–22 分钟：DNA，最古老的语言（第 11 页 → 打开）

- 准备：选学段（初中只做任务 1、2）；按 T 打开教师提示。开场可在“语言”页签用翻页笔切换“正常 → 同义 GAG→GAA → 镰刀型 GAG→GTG → 无义 GAG→TAG”：同义 = 同义词，镰刀型 = 错别字，无义 = 句号提前。
- 操作（“探究”页签，预测 → 操作 → 证据 → 解释 → 评价；序列是 HBB 编码区开头 9 个密码子）：
  1. 任务“三种‘错别字’”：用预设按钮或改字工具一次只改一个字母，同义、错义、无义各记一组——GAG、GAA 都编码谷氨酸；GAG→TAG 后面不再合成；
  2. 任务“镰刀型是怎么来的”：点“镰刀型 GAG→GTG”（第 7 个密码子，谷氨酸 → 缬氨酸，带电亲水变疏水）；再用改字工具把第 4 个密码子 CTG 改成 GTG（亮氨酸 → 缬氨酸，性质相近）对照；
  3. 高中任务“插入一个字母”：点“插入一个碱基”“删除一个碱基”，从改动处起读码框整体错位；追问插入 3 个碱基会怎样；
  4. 高中任务“后果为什么差别这么大”（开放题）：自己设计至少三种不同结果的突变。
- 提问：你在批改作文时见过的三种错误，在 DNA 里分别意味着什么？同样是错义突变，后果为什么不一样？
- 结论句：**一个字母的后果取决于它改成了什么、改在哪里：可能不变、可能改写细胞形状、可能让句子提前结束。**
- 边界：密码子计数含起始 Met，课本的“第 6 位谷氨酸”指成熟蛋白的位置；红细胞形态为示意，不是显微照片。
- 回退：30 秒没进入预期状态，只看数据卡与蛋白质链（不依赖 3D）；WebGL 打不开就播放备用录像，用密码子表手工翻译；全部失效时板书“THE CAT ATE THE RAT”，三个字母一组读，删掉一个字母再读。
- 选讲：第 11 页的第二个入口是“细胞膜运输实验舱”。
  - 先遮住右侧计数器只看粒子，再打开：外→内、内→外两个方向都在增加——“方向”说的是净移动；
  - ×10 快进到平衡，两个计数仍在等速增加：动态平衡不是静止；
  - 高中：协助扩散固定载体 4，把膜外从 40 提到 100，净速率接近上限；载体改 8，上限翻倍；
  - 高中：主动运输运行中关闭 ATP，计数立即停止；顺梯度时泵也在耗 ATP——判断依据是“耗能 + 载体”。

### 22–42 分钟：用坐标说话（第 12 页 → 打开）

- 准备：选学段（初中做任务 1、2、4）；按 T 打开教师提示。东经 104° 剖面、海平面上升 100 米、珠峰坐标只在“语言”页签的预设里，可开场或课末用翻页笔展示（珠峰只得到约 6850 米：约 5 km 网格的平均海拔）。
- 操作（“探究”页签，预测 → 操作 → 证据 → 解释 → 评价；本课约定 ≥3000 米第一级、500–3000 米第二级、<500 米第三级）：
  1. 任务“西高东低吗”：北纬 35° 剖面三级阶梯完整出现（第一级约东经 78°–103.5°，第二级约 103.6°–112°，第三级约 112° 以东），再点北纬 33° 对照；
  2. 任务“找一个反例”：北纬 40° 最高约 2350 米，没有第一级——“三级阶梯”是总体格局，不是每条剖面都完整；
  3. 高中任务“四川盆地属于哪一级”：北纬 31° 剖面，盆地底约 300 米，低于 500 米，按阈值第二级被断开；点“四川盆地”定位核对——追问“阶梯是按什么划分的”（教材以山脉为界）；
  4. 任务“平原有多少”：点“500 米以下”“3000 米以上”：约占陆地面积 28% 和 26%，联系人口分布；
  5. 高中任务“阶梯这个模型好不好”（开放题）：至少三次查询，找支持和反对自己分级方法的证据。
- 提问：课本上的“三级阶梯”是一张图，一句“沿北纬 31° 剖开”是一个指令。哪一个更能让学生自己去发现——包括发现课本说法的边界？
- 结论句：**一句带坐标的话，就是一个可以检验的指令；“级”是区域划分，不是等高线。**
- 边界：地形为公开 DEM（约 5 km 网格，垂直夸张 30 倍），仅作教学示意。
- 回退：30 秒没进入预期状态，只看剖面图和数据卡（不依赖 3D）；WebGL 打不开就播放备用录像，配合课本“中国地势三级阶梯示意图”；全部失效时在黑板上画北纬 35° 和 31° 两条剖面草图，让学员标出四川盆地。

## 第 6 课：从提示词到语言规格书（第 13–15 页）

### 0–15 分钟：语言规格书（第 13 页）

> 提示词不是咒语，它是给 AI 的项目任务书。前面 9 个学科案例，每一个都是一份写清楚了的规格书。

讲解六格：目标、概念、关系、画面、交互、验收。每讲一格，都回到某个已经看过的案例里指出对应物。例如“关系”这一格：古诗里的“直 / 圆”、介词、SMILES、坐标。

### 15–25 分钟：四个问题（第 14 页 → 方法卡）

> 说清目标、定义概念、写出关系、给出验收。这四个问题不只是写提示词的方法，也是我们要教给每个学生的思维方式。

方法卡 A4 双面打印，每人一份。

### 25–30 分钟：从能运行到敢上课（第 15 页）

三类错误：

- 事实错误：日期、公式、概念不可靠；
- 模型错误：画面让学生形成错误的因果；
- 工程错误：断网、字体缺失、触控失效。

每个现场操作都要有 30 秒回退路径。

### 30–45 分钟：Codex + Blender 彩蛋（第 15 页 → 打开）

- 五步精确提示词：每一步都对应一个可检查的参数（镜头焦距、喷发阶段与速度、太阳高度角、11 个结构标签、环绕角度）。
- 第 2 步点阶段条：蓄压 → 喷口破裂 → 闪光与冲击 → 高速气灰喷流 → 火山弹抛射 → 灰柱卷吸膨胀 → 灰尘沉降。先问“看到火了吗”：白天的灰柱是灰褐色的岩屑，火光只在喷口和火山弹上。
- 第 3 步夜景：炽热火山弹的轨迹；对照 1 km 比例尺估落点（模型中位数约 0.75 km，最远约 2.3 km）。
- 第 4 步剖面：点标签区分侵入岩（岩浆房外壳、岩墙、岩床、岩塞）与喷出岩（熔岩流层、火山碎屑层）。
- 强调：画面时间压缩 5 倍；这是原创教学模型，不复现某座真实火山。
- 电影版（页首“播放电影版”，约 35 秒）：同一次喷发的七个镜头——蓄压、剖面里的岩浆上涌、破裂（炽热碎屑与火山弹光迹）、冲击尘环、卷吸、冲出云层的 3.2 千米全景、夜晚。可先问“火山喷发时是在燃烧吗？”——发光的是约 1000°C 的碎屑和气体，不是燃烧的火焰。可作开场或收束；放完追问“哪一个镜头里能看出冲击波以声速传播？”（近景镜头一震的时刻）。灰柱与尘环借用 CC0 体积素材，按羽流理论缩放，来源见《来源与边界》。
- 现场用 MCP 真改的步骤，以 `blender/README.md` 为准。
- 结论句：**AI 能稳定操作 3D，是因为对象先被人用语言组织好了——说得越精确，世界越可控。**
- 回退：Blender 未连接，或渲染超过 30 秒，立即播放页面上的“播放完成版”或“播放修改版”录像。

## 第 7 课：工作坊——写你学科的那一句话（第 16 页 → 开始工作坊）

学员要求：自带电脑，能上网。

1. **选学科模板（5 分钟）**：打开 `#/workshop`，选择学科，可以先点“载入示例”看一份写好的规格书。
2. **写规格书（12 分钟）**：填写六格。页面会实时标出模糊词（例如“漂亮、生动、一些、合适”）并给出精确度提示，把模糊词改成数量、关系和条件。
3. **生成（10 分钟）**：
   - 点“生成提示词”并复制；
   - 粘贴到任一能输出网页代码的在线 AI 对话工具；
   - 让它输出单个 HTML 文件。
   - 工具能直接预览就直接看；不能预览就把代码存成 `.html`，用浏览器打开。
4. **一次只改一层（10 分钟）**：用页面提供的三条修改提示词，按顺序只改数据、只改交互、只改叙事。
5. **验收与互评（8 分钟）**：同桌交换，用“一分钟验收”逐条检查，看结论能否被画面支持，以及有没有教错。

> 讲师话术：AI 可以写代码，但什么算“教对了”，必须由教师决定。规格书写得越清楚，AI 做得越准。

## 第 8 课：收束与长征压轴（第 17–18 页）

### 0–8 分钟：AI 时代的教育重点（第 17 页）

> 以语言为核心的逻辑思维：会提问、会定义、会表达关系、会验证。

### 8–42 分钟：长征——空间是历史的条件（第 18 页 → 进入）

操作顺序：

1. **全景**：先停在全国全景，指出国界形状、三级阶梯和南海诸岛附图。
2. **自动巡航**：点“▶ 自动巡航”，镜头会依次飞到每个节点。
   - 到遵义时暂停，提问：“这是一处地理转折，还是组织和指挥转折？”
3. **节点详情**：点节点打开图文轮播。
   - 前几张是实景照片，来自 Wikimedia Commons 的 CC 或公有领域授权，带署名；
   - 腊子口和吴起镇用的是 AI 示意图，图上标有“AI 生成·示意图”，要向学员说明它不是历史影像；
   - 最后一页是“背景 / 经过 / 意义 + 课堂问题”。
4. **空间问题**：
   - 为什么四渡赤水不能用“绕远了”来解释？
   - 为什么泸定桥是瓶颈？
   - 为什么草地看似平坦，却属于自然险阻？
5. **退出**：Esc 逐级退出，先关详情，再回全景，最后回到主课件第 18 页。

### 42–45 分钟：全天结束语

> 从一个词向量，到一万二千公里的地形，今天所有的 3D 世界都是从一句说清楚的话开始的。AI 时代，我们教学生的最重要的东西，仍然是语言和逻辑。
