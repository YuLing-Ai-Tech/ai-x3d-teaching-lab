# 课堂应急卡

## 开课前 20 分钟

1. 关闭系统自动更新和通知；接通电源，关闭低电量模式。
2. 关闭其他占用 4173 端口的预览服务（或重启电脑），然后双击 `start-frozen.command`，浏览器打开 `http://localhost:4173/`。
3. 投屏为 1920×1080，浏览器缩放 100%，按 F 进入全屏。
4. 从主课件第 1 页翻到第 18 页，每个案例点进去再按 Esc，确认能回到原来那一页。
5. 每条备用录像各播放 5 秒，共 12 条 Web 录像和 2 条 Blender 录像。
6. 用真实手机扫码，打开一个案例。
7. Blender：只打开场景副本，不打开原始 `.blend`。
8. 工作坊：确认教室网络能打开至少两个在线 AI 工具，并准备一份已经生成好的示例 HTML 作为兜底。

## 操作速查

| 位置 | 翻页笔 / ← → | Esc |
|---|---|---|
| 主课件 | 翻页（Home 回第一页，End 到最后一页） | — |
| 语言实验室案例 | 切换预设 | 回到主课件原来那一页 |
| 长征 | 切换节点 | 先关详情，再回全景，最后回主课件 |
| 长征详情轮播 | 翻图片 | 关闭详情 |

## 30 秒规则

| 故障 | 立即动作 | 过渡句 |
|---|---|---|
| WebGL 黑屏或卡顿 | 刷新一次；仍失败就点页面底部“播放备用录像” | “我们切换到同版本录像，继续关注语言和画面的对应。” |
| 页面失去控制 | Esc 回主课件，重新进入；仍失败就播放录像 | “先保护课堂节奏，原理讲完后再看技术细节。” |
| 手机扫不进 | 口头报局域网地址；仍失败就只投屏 | “交互入口暂时由我代操作，观察任务不变。” |
| 工作坊在线工具打不开或很慢 | 换另一个工具；仍失败就展示兜底示例 HTML，学员只写规格书 | “今天最重要的产出是规格书，生成可以课后完成。” |
| AI 生成的网页运行报错 | 把报错原文贴回 AI，只要求修这一处；两次不成功就换示例 | “这就是验收的意义：先发现问题，再一次只改一层。” |
| Blender 未连接 | 检查一次插件面板；仍失败就播放完成版 | “高阶工具的价值和边界，都在这个失败里。” |
| 渲染超过 30 秒 | 停止渲染，播放修改版 | “实时渲染让位于教学时间，比较任务继续。” |

## 不在现场做

- 不更新依赖、Blender 或 MCP。
- 不改长征史实数据和案例预设。
- 不输入没彩排过的新提示词来演示本系统。工作坊里学员自己的生成不受这条限制。
- 不覆盖原始 `.blend`。
