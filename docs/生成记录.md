# 生成记录

## Web 3D 案例

- 生成日期：2026-10-14；长征 GIS 场景升级日期：2026-10-15。
- 代码与交互：本项目 `src/`，使用 TypeScript、Vite、Three.js、MapLibre GL JS、deck.gl 与 maplibre-contour；无运行时 AI 接口。
- 地形：`scripts/build-terrain.py` 在制作期读取公开 Terrarium 瓦片；`scripts/publish-terrain-tiles.py` 将 117 张真实 DEM 瓦片与离线低缩放级瓦片写入 `public/terrain/`。课堂运行只读本地文件。
- 长征地图：MapLibre 在 GPU 中渲染 `raster-dem` 地形、山体阴影和镜头；maplibre-contour 从同一 DEM 即时生成等高线；deck.gl 渲染路线光流、行军粒子、节点和中文标签。原 Three.js 场景保留为自动回退。
- 地图轮廓：`scripts/build-china-outline.mjs` 从本地锁定的 `world-atlas 2.0.2` 生成概化 GeoJSON；雨层由本项目实时生成。
- 录像：`scripts/record-web-demos.mjs` 从生产构建逐项操作 12 个 Web 案例，再转码为 1920×1080 H.264。

## Blender 火山（2026-10-26 重建）

- Blender：5.2.2 LTS，Cycles + Metal，Filmic（AgX 会把 Blackbody 熔岩渲染成粉色）。
- 场景：`blender/build_volcano.py` 调用 `terrain.py`（高度场 + 水蚀 + 火口岩塞 + 老熔岩流）、`geology.py`（剖面地质图）、`surface.py`（地表反照率与热图）、`volcano_scene.py`（网格、材质、灯光、镜头）、`eruption.py`（岩塞、Mantaflow 灰柱、火山弹、闪光、落地扬尘）。固定种子 20261029。
- 灰柱：`blender/bake_plume.py` 烘焙到 `.cache/volcano-bake`；火山弹：`blender/ballistics.py`（带空气阻力的 RK4，落在高度场上）。
- 五步渲染：`blender/render_steps.py`；编码：`scripts/build-blender-videos.py`；验收：`scripts/build-blender-verify.py`（闪光亮度峰值、灰柱面积增长、运动量、标签在画内、编码与时长）。
- 现场修改复现：`blender/live_edit.py` 把岩浆发光强度 4→9、切到 `Camera_Section`（35 mm），输出 `LIVE_EDIT_OK`。
- 一键重建：`scripts/build-blender-assets.sh`，各阶段耗时写入 `.cache/volcano-build/timing.txt`。
- 外部资产：无。地形、贴图、灰柱、火山弹全部由脚本生成，没有下载第三方模型、贴图或 HDRI。
- 旧分支 `codex/blender` 的 18787e4、2474147 未合入；只参考了其阶段时间轴、两类喷发物、种子化随机与运动验收思路。

## AI 使用边界

- AI 用于需求拆解、代码生成、脚本生成、测试与修改建议。
- 本机安装了 `3d-web-experiences` 与 `threejs` 两个开源技能，用于后续 3D 视觉与 Three.js 工作流参考；本轮成品以仓库代码、主库文档和浏览器实测为准。
- 历史日期、地点与事件表述由人工对照来源台账；无法承诺测绘精度的部分标为教学示意。
- 数学、生物和火山场景属于教学概念模型，页面与讲师稿均明确其非科研仿真属性。
