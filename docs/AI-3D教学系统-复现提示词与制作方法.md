# AI 时代以语言为核心的教学 · HTML 3D 演示系统
## 复现提示词与制作方法

> 用途：把本文件整段交给任何一个能写代码的 AI（Claude Code、Codex、Cursor 等），它就能从零复现这套系统；老师也可以只读第 3、4 节，学会“把一个知识点写成能让 AI 做出 3D 课件的语言规格书”。
> 本项目路径：`培训课程/高中教师AI应用培训-20261029/`，开课：双击 `start-class.command`（局域网二维码）或 `start-frozen.command`（只需系统 Python，直接打开已验收的 `dist`）。

---

## 1. 一句话主张（所有页面都为它服务）

**大语言模型就是语言的模型。中文、英文、数学、代码、化学式、DNA 都是“用符号表达关系”的语言；谁能把话说清楚，谁就能让 AI 把世界造出来。以语言为核心的逻辑思维，是 AI 时代教育的重点。**

每个 3D 页都是同一个形式：**左边一句可以改的“语言”，右边是它描述的 3D 世界**。改一个字，世界就变；悬停一个词，3D 里对应的东西亮起来。

## 2. 直接复制给 AI 的总提示词

```text
你是一名资深前端 / WebGL 工程师兼教学设计师。请用 Vite + TypeScript + Three.js（不用 React）做一个
“AI 时代以语言为核心的教学”HTML 3D 演示系统，给高中教师做一天培训。要求：

【主线】大语言模型 = 语言的模型；中文、英文、数学、代码都是表达关系的语言；以语言为核心的逻辑思维是教育重点。
【形式】每个案例页：左栏是一段可编辑的“语言”（输入框 + 词块高亮 + 预设按钮 + 课堂问题），
        右栏是 3D 世界；改一个词，3D 世界实时重组；悬停词块，3D 中对应对象高亮；右下角一张小讲解卡（≤360px 宽），
        3D 主体自动避让讲解卡并保持在视觉中央。
【视觉】高级、科技感、有冲击力：深色背景、辉光后期（UnrealBloom）、全息网格地面、漂浮粒子、电影式镜头缓动；
        写实场景要真实质感（例如行星不自发光，只有太阳是光源；地形用真实 DEM）。所有文字用 HTML 叠层，不用贴图文字。
【讲课流程】
  - 只有一个讲课顺序（catalog.ts）：AI 认知 → 语言为王 → 学科巡礼 → 方法与工作坊 → 长征压轴。首页分组、主课件跳转、
    案例页“上一个 / 下一个”全部读这一个列表。
  - 主课件地址带页码：#/deck?s=N（翻页用 history.replaceState 写回）。从第 N 页点“打开 xx”进入 #/xx?from=N。
  - 每个案例页顶栏：“← 返回主课件 · 第 N 页”、上一个案例、位置 k/总数、下一个案例。

  - 翻页笔（← → / PageUp PageDown）：主课件里翻页；案例里切预设；长征里切节点；详情弹窗里翻图片。
【可靠性】全部离线运行（数据课前烘焙进 public/），不请求外网；每个案例有备用录像；1920×1080 和 1366×768 都不遮挡文字。
【验收】vitest 测语言解析器与讲课顺序一致性；Playwright 测每页无控制台错误、预设可切换、返回逻辑；
        排版巡检脚本检查文字裁切 / 浮层互相遮挡 / 超出画面，并人工看截图。
请先搭共享框架（langLab 页面骨架 + cinematic 舞台 + flow 导航），再逐个做案例，每做完一个就截图自查。
```

## 4. 每个案例的“语言规格书”（六格写法，可直接作为单页提示词）

> 六格：①目标（学生最后能说出哪一句话） ②概念（关键词指什么） ③关系（谁和谁怎样相关） ④画面（必须出现哪些对象） ⑤交互（学生能改变什么） ⑥验收（怎样判断没有教错）。

### 第一章 · AI 是语言模型
**词向量宇宙**（`#/embedding`）
① 词义 = 高维空间中的位置；中英文共享同一意义空间。② 本机 Ollama `bge-m3` 计算 108 个中英文词向量（54 对）（`scripts/build-embeddings.py`），t-SNE 投到 3D，类比在原始 1024 维计算。③ 星空中的词（颜色=类别）、中英同义词之间的光桥。④ 输入一个词或 `A − B + C`。⑤ 邻居连线；king − man + woman 箭头指向 queen。⑥ 相似度来自真实模型；类比不完美时如实标“不完美”。

**下一个词**（`#/next-token`）
① LLM 只做一件事：预测下一个词。② 本机 Qwen3.8-27B（bf16，mlx-lm）对 6 句话逐步取前 8 个候选概率（`scripts/build-next-token.py`），课前预生成。③ 8 根光柱（第一名居中），胜出的词“射入”句子。④ 选预设句子。⑤ “霜 99.8%” vs “提问 10.5%”。⑥ 概率为真实输出。

### 第二章 · 语言为王
**语言编译台**（`#/compiler`）
① 中文 / English / 数学 / 代码 是同一世界的四种写法；模糊词 = 交出决定权。② 规则解析器（球、螺旋、圆锥、波浪面、圆环）。③ 7000 粒子按句子重组形状，尺寸线。④ 改句子。⑤ 四种写法同步；“漂亮的”标红，未说清的数量提示“只能猜”。⑥ 单元测试：中英文得到同一参数。

### 第三章 · 学科巡礼
- **语文 · 古诗即几何**：逐字规则（直/斜/乱、圆/缺/半、孤/群、日/月、落/旭），黄昏大漠电影画面，烟用着色器平滑变形，悬停形态字描出构图线。
- **英语 · 介词即空间**：13 个名词 × 15 个介词，每个介词给出空间逻辑式；through 只接受有“开口”的参照物（隧道 / 窗 / 门），否则提示“穿过去就是穿墙”；around 用低机位让主体转到背面时被遮挡。
- **数学 · 圆锥曲线**：预测 → 拖动切面 → 解释临界角。
- **物理 · 一句话定义引力**：从句子读出幂次 n（平方/立方/正比/English/质量加倍），实时积分；只有 n=2 与 n=−1 闭合（贝特朗定理）；行星为程序生成写实纹理，仅受太阳点光源照明，无自发光。
- **化学 · 分子也有语言**：SMILES 词块（原子/键/支链/成环）；RDKit 课前生成 18 个分子 3D 构象（`uv run --with rdkit`）；同分异构自动提示。
- **生物 · DNA**：真实 HBB 开头 9 个密码子；同义 / 错义（GAG→GTG 镰刀型，红细胞变形）/ 无义（提前终止）。
- **生物 · 细胞膜**：改变浓度、通道、ATP 观察运输方式。
- **地理 · 用坐标说话**：全国 5 km DEM 沙盘，按国界切形（DataV 标准画法轮廓 + mask）；剖面、海平面、等高面、坐标定位。

### 第四章 · 方法与工作坊
语言规格书工作坊（学科示例 + 模糊词检测 → 给在线 AI 工具的单文件 HTML 提示词 → 一次只改一层）；方法卡（可打印）；Codex + Blender 彩蛋（只开放五项受控修改，30 秒回退规则）。

### 压轴 · 长征 3D 地形叙事（`#/long-march`）
① 空间是历史的条件。② z7 DEM 全国沙盘（垂直夸张 9 倍），水系由高程推算（priority-flood + D8），国界 DataV；63 个途经点；节点讲解 `src/data/routeStories.ts`（背景 / 经过 / 意义，党史权威通行口径）。③ 中国形状沙盘、贴地路线逐段“长出”、红旗、雪山下雪、南海诸岛附图（含断续线）。④ 时间轴 / 地图点选 / 翻页笔 / 自动巡航 / 俯视。⑤ 再点一次节点打开**图文轮播**：Wikimedia Commons CC/PD 实景照片（标作者+许可）；无照片节点用本机 FLUX.2-klein-4B 生成，统一 16:9 调色、暗角、颗粒，并醒目标注 **“AI 生成 · 示意图”**；最后一页为讲解 + 课堂问题。⑥ 路线为教学示意，不作测绘依据。

## 6. 踩过的坑（复现时直接避开）

1. **地图合规**：不要用 Natural Earth 等国外轮廓画中国；用 DataV（含藏南、台湾、南海诸岛、断续线），南海用附图。
2. **国界裁切的“冰柱”**：不要按网格三角形裁切，用 mask 贴图 `alphaTest` 逐像素裁；侧壁顶边做滑动平均。
3. **讲解卡挡主体**：卡片缩小 + `camera.setViewOffset` 轻微避让，而不是把主体推到画面顶部。
4. **through 穿模**：参照物必须真的有开口，路径高度对准开口中心；材质要写深度，主体转到背后才会被挡住。
5. **写实天体**：只有太阳是光源，行星关掉自发光与半球光；Bloom 阈值调高到只让太阳发光。
6. **返回第 1 页**：主课件必须把页码写进地址；进入案例带 `from=N`；Esc 让页面自己的处理先执行（`preventDefault`）。
7. **历史影像**：1934–35 年原始影像几乎不存在，纪录片有版权；用 CC/PD 照片 + 标注清楚的 AI 示意图。
8. **网络**：Wikimedia 会 429 限流（加间隔与退避）；地形瓦片下载会断（写临时文件 + 重试）。
9. **地形配色别只按海拔**：同样 1000 米，塔里木是沙漠、江南是森林。用“湿润 / 干旱”两套海拔色带，按约 400 mm 等降水量线过渡；雪线放到约 5900 米，否则整个青藏高原会被染白。河流画成单像素的低饱和细线，宽带在近景下会像洪水。
10. **全国尺度看不清路线**：加一条随镜头距离淡入的粗发光管道，用沿路线流动的光脉冲表现行军方向；沙盘下方放一块带 5° 经纬网和北回归线的深色台面，代替纯黑背景。
11. **备用录像**：`scripts/record-web-demos.mjs` 会自动把每个语言实验室案例的预设依次点一遍，录成 1920×1080 H.264；页面底部的“播放备用录像”直接指向它。
12. **与 Codex 并行开发**：项目用 git 管理；Codex 在独立的 worktree 和分支里工作，按任务书只能改约定的文件；端口也分开（Claude 用 5199/4273，Codex 用 5299/4299）。合并由一方负责。
