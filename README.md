# 智境 AI × 3D 教学实验室

**毓灵 YuLing AI · AI × 3D Teaching Lab**

面向小学、初中和高中的本地优先 3D 教学实验项目。项目从已经完成的高中教师培训系统起步，逐个沉淀可操作、可验证、可离线运行的教学实验。

当前仓库正在建立公开基线。完整课堂运行包包含部分不能公开再分发或体积较大的本地资产；这些资产不进入 Git 历史，详见 `BASELINE_MANIFEST.md`。
